## Подробности

**Пословный русский перевод: пример из QUL (73:4).** أَوْ → «или», زِدْ → «прибавь», عَلَيْهِ → «к этому», وَرَتِّلِ → «и читай», ٱلْقُرْءَانَ → «Коран», تَرْتِيلًا → «размеренным чтением». Качество хорошее, это лучший вариант. Если разрешение не дадут, придётся делать черновой перевод с английского пословного и вычитывать его.

**Тафсир ас-Саади: проблема с привязкой.** Запрос тафсира к аяту 114:1 вернул текст про суру Аль-Фалак (113). Тафсир, видимо, разбит на группы аятов, и привязка может съезжать. Каждую суру нужно сверять, поэтому в проекте есть агент `content-verifier`.

**Причины ниспослания и хадисы.** Их **нельзя брать из ответов ИИ**: возможны ошибки и выдуманные ссылки. Только из книги или сайта, с указанием источника и степени достоверности. Если для суры ничего достоверного нет, приложение так и пишет.

**quran.com API.** `api.quran.com/api/v4` отвечает без ключа. Параметр `word_translation_language=ru` молча возвращает английский, то есть пословного русского там нет.
