# Экран «Карточка слова»

Спецификация от агента `ios-designer`, 29.10.2026. SwiftUI, iOS 18+. Статус: черновик, ждёт решения владелицы.

## Каркас

- `NavigationStack`, заголовок `.inline` («Новые слова» / «Повторение»), справа счётчик «3 / 12», слева `xmark`. Под навбаром тонкий `ProgressView`.
- Карточка в `ScrollView`, нижние кнопки через `.safeAreaInset(edge: .bottom)`.
- Отступы: поля страницы 16 pt; внутри карточки 20 pt (24 pt при ширине ≥ 400 pt); радиус карточки 20 pt (`.continuous`); между секциями 24 pt, внутри 8–12 pt.
- Тень только в светлой теме: `.shadow(color: .black.opacity(0.06), radius: 12, y: 4)`.

## Лицевая сторона

1. Чип знакомости слева, «114:1» справа (`.footnote`).
2. Слово: Amiri Quran 64 pt (`relativeTo: .largeTitle`), по центру, с фоном и чертой знакомости.
3. Кнопка озвучки 52 × 52 pt (`.bordered`, `.circle`). До версии 0.3 кнопку скрываем.
4. `Divider`, подпись «Аят 114:1», аят Amiri Quran 28 pt, справа налево. Текущее слово `ink` с подсветкой, остальные `inkDim`. Перевод аята здесь не показываем.
5. Внизу «Показать ответ» (`.borderedProminent`, `.large`, на всю ширину).

Минимальная высота карточки около 60% экрана, чтобы слово было в оптическом центре.

## Оборот

1. Слово с раскраской сегментов (48 pt) + маленькая кнопка озвучки; транскрипция (`.title3`, курсив); перевод (`.title2`, `.semibold`).
2. «Из чего состоит»: плитки сегментов справа налево [بِ] + [رَبِّ]. В каждой сегмент 34 pt цвета роли, подпись роли (`.caption`) и значение (`.footnote`). Фон цвета роли с прозрачностью 10% (в тёмной теме 18%), сверху полоска 3 pt.
3. «Грамматика»: `Grid` с подписями слева (~110 pt) — часть речи, корень (буквы через пробел), лемма, род, число, падеж с арабским термином.
4. «Почему так»: плашка `focusNeutral` с тегом «Черновик» при `draft: true`.
5. «Встречалось раньше»: строки-кнопки «1:2 · фрагмент · чип · ›», высота ≥ 44 pt. По нажатию sheet с экраном «Аят» (`.medium`, `.large`).
6. Аят целиком (24 pt).
7. Подпись источников: «Морфология: Quranic Arabic Corpus · Текст: Tanzil» (`.caption2`).
8. Внизу четыре кнопки оценки.

## Взаимодействие

- **Переворот:** по тапу на карточку и по кнопке. `rotation3DEffect` по Y на 180°, `.spring(duration: 0.45, bounce: 0.1)`, `perspective: 0.4`. При «Уменьшении движения» простое затухание за 0.2 с. Лёгкий тактильный отклик. Обратно карточка не переворачивается.
- **Свайпы для оценки не используем:** слишком велик риск случайной оценки.
- **Кнопки оценки:** «Снова», «Трудно», «Хорошо», «Легко» равной ширины, высота ≥ 56 pt, интервал строкой ниже (`.caption`, `.monospacedDigit`). «Хорошо» `.borderedProminent`, остальные `.bordered` серые. Красно-зелёной раскраски нет. При крупном шрифте кнопки перестраиваются в сетку 2 × 2.
- **Озвучка:** символ `speaker.wave.2.fill` с `.symbolEffect(.variableColor.iterative)` во время воспроизведения. Опция «Озвучивать при открытии ответа» по умолчанию выключена.
- **VoiceOver:** «бираббӣ, та же форма, текущее слово»; «Хорошо, следующее повторение через 10 минут»; арабскому тексту `accessibilitySpeechLanguage = "ar"`.

## Шрифт

- **Основной: [Amiri Quran](https://github.com/aliftype/amiri)**, лицензия SIL OFL 1.1, версия 1.003. Насх для набора Корана, поддерживает знаки Tanzil Uthmani: ٱ, малый алиф, малые высокие знаки, знаки остановки, ﴿﴾.
- **Запасной: [Scheherazade New](https://software.sil.org/scheherazade/)** (SIL OFL), для мелких мест.
- **Не берём KFGQPC Uthmanic Hafs:** у него не OFL, лицензия запрещает изменения.
- **Подключение:** положить `AmiriQuran-Regular.ttf` и `OFL.txt` в проект, добавить шрифт в `Info.plist` → `UIAppFonts`, проверить имя через `UIFont.familyNames`.
- **Что проверить в симуляторе:** ٱلْعَٰلَمِينَ и ٱلنَّاسِ.

## Заметки для реализации

- `layoutDirection(.rightToLeft)` ставим только контейнерам арабского текста. Русский текст, «114:1» и транскрипция остаются слева направо.
- Аят выкладывается своим `FlowLayout`, каждое слово отдельным `Text`; под `.rightToLeft` зеркалится только расположение блоков. Проверить в симуляторе на первом аяте.
- Цвет сегментов задаётся через `AttributedString` с тем же шрифтом, чтобы буквы продолжали соединяться. Огласовки входят в свой сегмент.
