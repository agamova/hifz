# План первой версии

## Идея

Учить суру через слова: сначала история суры, потом карточки слов с разбором, потом аяты с переводом. Повторения по алгоритму FSRS, чтобы не забывался смысл. Знакомые слова и корни подсвечиваются в тексте.

## Объём первой версии

Четыре суры: **Аль-Фатиха (1), Аль-Ихлас (112), Аль-Фалак (113), Ан-Нас (114)**. Этого хватит, чтобы проверить весь путь и сразу увидеть подсветку повторяющихся слов (رَبّ, ٱلنَّاس, شَرّ, أَعُوذُ). Остальной джуз «Амма» добавим, когда всё заработает.

## Принципы

- **Работает без интернета.** Все данные лежат в самом приложении.
- **Данные готовятся заранее.** Скрипт собирает текст, морфологию, переводы и тафсир в один файл; приложение его только читает.
- **Религиозное содержание только из источников.** У каждой истории ниспослания и каждого хадиса есть ссылка и степень достоверности. Объяснения грамматики, написанные ИИ, помечены как черновик.
- **Одна карточка на слово (лемму).** Повторные встречи слова подсвечиваются в тексте, но новых карточек не создают.

## Подсветка слов

| Цвет | Значение | Пример |
|---|---|---|
| Без цвета | Новое слово | — |
| Цвет 1 | Это слово в этой же форме уже встречалось | رَبِّ в 113:1 после 114:1 |
| Цвет 2 | Та же лемма в другой форме (число, род, падеж) | رَبّ ↔ رَبَّ |
| Цвет 3 | Тот же корень, другое слово | مَلِك ↔ مَالِك (корень م ل ك) |

Нажатие на слово открывает его карточку и показывает, где оно уже встречалось.

## Экраны

1. **Мои суры.** Список сур с прогрессом: сколько слов и аятов выучено.
2. **Сура.** Название, мекканская/мединская, история ниспослания (если есть, со ссылкой), список аятов, кнопка «Учить слова».
3. **Карточка слова.**
   - Лицевая сторона: слово с огласовками, кнопка озвучки, цвет знакомости.
   - Оборот: транскрипция, перевод, разбор по частям (بِ + رَبِّ), часть речи, род, число, падеж и почему, корень, лемма, где ещё встречалось.
   - Кнопки оценки как в Anki: «Снова», «Трудно», «Хорошо», «Легко».
4. **Аят.** Текст с подсветкой слов, перевод, тафсир, озвучка, кнопка «Выучен».
5. **Повторение на сегодня.** Очередь FSRS: слова и смысл аятов.
6. **Сура выучена.** Поздравление и достоверные хадисы о суре, если они есть.

Дизайн экранов (цвета, шрифты, вид карточек) прорабатываем с агентом `ios-designer` перед тем, как писать каждый экран.

## Технологии

- **Swift + SwiftUI**, iOS 18+.
- **SwiftData** для прогресса и расписания повторений.
- **Данные Корана**: один SQLite-файл внутри приложения.
- **Арабский шрифт**: шрифт с открытой лицензией для Корана (выбираем вместе с дизайнером).
- **FSRS**: готовый Swift-пакет или собственная реализация (алгоритм небольшой).
