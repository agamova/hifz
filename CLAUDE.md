# hifz

iPhone-приложение для заучивания Корана с изучением арабского по ходу: история суры → карточки слов с грамматическим разбором и интервальным повторением (FSRS) → аяты с переводом и тафсиром → отметка «выучено».

- План первой версии: `docs/mvp-plan.md`
- Источники данных и их лицензии: `docs/sources.md`

## Общение

- Владелица проекта начинает программировать. Объяснять просто, по-русски, без лишнего жаргона.
- Предлагать лучшее решение самим, не дожидаясь вопроса.

## Правила по содержанию

- Хадисы, причины ниспослания и тафсир **никогда не генерировать**: только из источника со ссылкой и степенью достоверности. Перед добавлением проверять агентом `content-verifier`.
- Текст Корана (Tanzil) и морфологию (Quranic Arabic Corpus) не изменять; указывать источник со ссылкой.
- Грамматические объяснения, написанные ИИ, помечать как черновик (`draft: true`), их готовит агент `arabic-grammar`.

## Технологии

Swift + SwiftUI, iOS 18+, SwiftData для прогресса, данные Корана в SQLite внутри приложения, работа без интернета. Новые экраны сначала проектируются агентом `ios-designer`.
